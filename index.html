Install DG Store

You can add DG Store to your phone's home screen for app-like access.

  1. Open the published DG Store website in Chrome.
  2. Tap Chrome's three-dot menu (⋮).
  3. Choose Install app or Add to Home screen, then confirm.

Important: Install options usually appear only when DG Store is published on an HTTPS website. Opening index.html directly from Downloads cannot install the PWA.
